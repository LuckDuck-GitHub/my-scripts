# my-scripts


# Для Python скрипта
pip install requests dnspython concurrent futures

# Для bash скрипта
sudo apt-get install curl ping traceroute mtr speedtest-cli -y

# Дополнительные утилиты для диагностики
sudo apt-get install netcat dnsutils tcptraceroute -y


Что проверяет скрипт:
DNS разрешение - корректность разрешения доменных имен

HTTP/HTTPS доступность - возможность загрузки страниц

Скорость соединения - тест скорости с разных CDN

TCP подключение - доступность портов

Стриминговые сервисы - YouTube, Twitch, Netflix

Мессенджеры - Discord, Telegram, WhatsApp

Геоблокировки - проверка ограничений по регионам

Cloudflare доступ - работа через популярный CDN

Критерии оценки:
✅ Отлично: Все сервисы доступны, скорость > 50 Мбит/с

⚠️ Удовлетворительно: Основные сервисы доступны, скорость 10-50 Мбит/с

❌ Проблемы: Сервисы недоступны или скорость < 10 Мбит/с

Рекомендации при проблемах:
Используйте VPN если обнаружены блокировки

Смените DNS на 8.8.8.8 или 1.1.1.1

Проверьте маршрутизацию через traceroute

Обратитесь к хостинг-провайдеру для уточнения политик

Рассмотрите VDS за пределами РФ если нужен стабильный доступ ко всем сервисам

Этот комплексный скрипт поможет понять, какие зарубежные сервисы будут доступны с вашего VDS и с какими ограничениями вы можете столкнуться.
