VDS Diagnostic Toolkit
Набор скриптов для комплексной диагностики VDS серверов с проверкой доступности российских и зарубежных сервисов. Инструмент помогает оценить пригодность VDS для работы с различными онлайн-сервисами, включая банковские системы и международные платформы.

Установка зависимостей
Для Python скриптов:
bash
pip install requests dnspython
Для Bash скриптов (Linux/Unix):
bash
sudo apt-get update
sudo apt-get install curl ping traceroute mtr speedtest-cli -y
sudo apt-get install netcat dnsutils tcptraceroute -y
Альтернативно для CentOS/RHEL:
bash
sudo yum install curl ping traceroute mtr nc bind-utils -y
pip3 install speedtest-cli
🎯 Использование
Основной Python скрипт проверки:
bash
# Проверка доступности зарубежных сервисов
python3 check_foreign_services.py

# Проверка соответствия российским требованиям
python3 check_russian_compliance.py

# Сохранение отчета в файл
python3 check_foreign_services.py 2>&1 | tee report.log
Bash скрипт мониторинга:
bash
# Дайте права на выполнение
chmod +x service_monitor.sh

# Запуск мониторинга
./service_monitor.sh

# Запуск в фоновом режиме
nohup ./service_monitor.sh > monitor.log &
📊 Скрипты
1. check_russian_compliance.py
Проверяет VDS на соответствие требованиям для работы с российскими ресурсами:

Геолокация IP-адреса

Принадлежность к российским ASN

Наличие в реестрах блокировок

Доступность российских банковских сервисов

2. check_foreign_services.py
Проверяет доступность международных сервисов:

YouTube, Twitch, Netflix

Discord, Telegram, WhatsApp

GitHub, Google сервисы

Cloudflare CDN

3. service_monitor.sh
Bash скрипт для непрерывного мониторинга доступности сервисов.

4. network_diagnostics.sh
Дополнительные сетевые проверки и диагностика.

🔍 Проверяемые параметры
Сетевая диагностика
DNS разрешение - корректность разрешения доменных имен

HTTP/HTTPS доступность - возможность загрузки страниц

Скорость соединения - тест скорости с разных CDN

TCP подключение - доступность портов

Ping и задержки - измерение сетевых задержек

Сервисная доступность
Стриминговые сервисы - YouTube, Twitch, Netflix

Мессенджеры - Discord, Telegram, WhatsApp

Облачные платформы - GitHub, GitLab, Docker Hub

Банковские системы - Альфа-Банк, Сбербанк, Тинькофф

Географические проверки
Геолокация IP - определение страны и региона

Геоблокировки - проверка региональных ограничений

CDN доступность - работа через популярные сети доставки контента

⚖️ Критерии оценки
Качество соединения
Статус	Скорость	Доступность сервисов	Рекомендация
✅ Отлично	> 50 Мбит/с	Все сервисы доступны	Идеально для стриминга и работы
⚠️ Удовлетворительно	10-50 Мбит/с	Основные сервисы доступны	Подходит для большинства задач
❌ Проблемы	< 10 Мбит/с	Сервисы недоступны	Требует оптимизации или смены провайдера
Соответствие российским требованиям
Параметр	Требование	Значение для "белых списков"
Геолокация	Россия (RU)	Обязательно
ASN	Российский провайдер	Желательно
Блокировки	Отсутствие в реестрах	Обязательно
DNS	Корректное разрешение .ru доменов	Обязательно

Смените DNS серверы:

bash

# Российские DNS
DNS: 77.88.8.8 (Яндекс) или 178.235.43.2 (Ростелеком)
Проверьте маршрутизацию:

bash
# Трассировка до проблемного сервиса
traceroute youtube.com
mtr --report discord.com

Конфигурационный файл

json
{
  "russian_services": [
    "alfa-bank.ru",
    "sberbank.ru",
    "gosuslugi.ru",
    "yandex.ru",
    "vk.com"
  ],
  "foreign_services": [
    "youtube.com",
    "discord.com",
    "github.com",
    "twitch.tv",
    "netflix.com"
  ],
  "speed_test_files": {
    "small": "https://example.com/1mb.test",
    "medium": "https://example.com/10mb.test",
    "large": "https://example.com/100mb.test"
  },
  "check_intervals": {
    "quick": 30,
    "standard": 300,
    "detailed": 1800
  }
}
Автоматизация проверок
Добавьте в crontab для регулярных проверок:

bash
# Ежедневная проверка в 2:00
0 2 * * * /usr/bin/python3 /path/to/check_foreign_services.py

# Еженедельный отчет по воскресеньям
0 4 * * 0 /usr/bin/python3 /path/to/check_russian_compliance.py
